# GitSpace

GitSpace is a self-modifying browser workspace spanning machines you own and cloud resources you create. You or an agent can change GitSpace in place from a GitSpace workspace without interrupting unrelated work.

The web app is the product. Connect a browser with an invitation from a connected browser or your saved recovery key. The `gitspace` command enrolls a computer, starts its machine runtime, and opens your account URL.

## What you can do in the browser

- See physical machines and managed sandboxes, including their available capabilities, in one fleet.
- Keep closed agent workspaces in cloud storage and place open work on the machine that should run it.
- Run coding agents and answer structured questions without digging through terminal output.
- Move work through `plan`, `code`, `review`, and `ship`.
- Inspect goals, workflows, rubrics, journals, review threads, change guides, artifacts, services, and events.
- Manage plugins, skills, crons, secrets, inbox items, and account settings.
- Launch a workspace release and keep its operational state next to the change.
- Modify and release GitSpace itself from a workspace without interrupting other accounts or active work.
